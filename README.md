# Tchatche

Ton pen pal français, en app sur l'écran d'accueil : conversation, prononciation avec micro, phrases en répétition espacée, images à décrire. Marche hors-ligne.

Ouvre le site GitHub Pages de ce dépôt sur ton téléphone, puis ajoute-le à l'écran d'accueil.
Tes données restent sur ton appareil : rien n'est stocké dans ce dépôt.
